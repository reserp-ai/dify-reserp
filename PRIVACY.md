# Privacy Policy

This plugin lets a Dify application call the public Reserp Google Search API.

## Data sent

- The complete Google Search URL supplied to the tool is sent over HTTPS to `api.reserp.ai` to execute the request.
- The user's Reserp API key is sent as an `Authorization` bearer header so Reserp can authenticate the account.

## Plugin collection and storage

The plugin does not collect, store, log, analyze, or share user data. It keeps no state, adds no analytics, and contacts no service other than the public Reserp API.

Reserp's terms are available at https://reserp.ai/terms.
